# Leer Afrikaans
1. Create a GitHub repo and upload everything in this folder (keep `.github/workflows/audio.yml`).
2. Settings > Pages > deploy from the main branch.
3. Actions tab > "Generate audio" > Run workflow. This creates a voice recording for every word and phrase. Wait for it to finish.
4. Open your Pages link on your iPhone in Safari, then Share > Add to Home Screen.
5. Optional: in the app's Settings, add a GitHub token (classic, "gist" scope only) to back up progress.
Microphone practice works best when opened in Safari, not from the Home Screen icon.
